# Code of Conduct

## Our pledge

We build Absolute Blockchain **Experimental** as an evidence-first R&D sandbox. Contributors and visitors keep discussions technical, respectful, and honest about what is proven vs not proven.

## Standards

- Be precise: link labs, hard-gate output, or ADRs when making claims.
- Do not pressure others to treat this sandbox as a launched public mainnet, the Hybrid audit pin, investment product, or audited DeFi.
- Lab PASS ≠ prod libp2p cutover ≠ 48h soak.
- No harassment, spam, or secret-dumping (`.env`, private keys, JWTs).
- Assume good faith; prefer patches and failing tests over insults.

## Enforcement

Report abusive behavior to the repository owner via GitHub or the contact listed in [SECURITY.md](SECURITY.md). Maintainers may close issues/PRs that violate this code or the honesty rules in the README.
